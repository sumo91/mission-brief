# Mission Brief: first-run preview guide

## Outcome

A technically inexperienced reader can locate the sample project, run its local preview, and identify the generated output location without developer explanation.

## Success

- Starting from this fixture directory, the guide identifies the project directory and the preview command.
- Following the guide produces a preview location that opens the finished page.
- The reader can state where the generated page is stored.

## Evidence Required

Have a reader who did not implement the fixture follow the finished guide from the fixture root. Record the commands attempted, the preview location, the generated output path, failures, and uncertainty.

## Boundaries

- Use the local fixture and installed Node.js only.
- Do not require global packages, network access, or developer explanation.
