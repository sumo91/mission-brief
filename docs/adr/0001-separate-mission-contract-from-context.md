# Separate the Mission contract from durable execution context

A Mission Brief remains the compact normative contract for one independently verifiable result; it does not become a compressed final plan or knowledge archive. Material non-contract information must still receive an explicit durable destination when losing it would erase known dependencies, risks, rationale, or costly investigation: preserve it in an existing Authority Source or Reference Source, or create an appropriate context record, while labeling its authority accurately. Mission 0 uses the same `brief.md` artifact in a parent integration role, and physical folders follow documentation ownership while explicit links carry parent-child topology. This separation preserves route freedom and stable review semantics without making compression a license for silent information loss.

## Considered options

- **Put the complete plan in every Brief:** rejected because execution routes and progress change faster than the result contract, would make review semantics unstable, and would turn a handoff into a copied knowledge archive.
- **Map every source sentence into the Brief or a disposition table:** rejected because sentence identity is not the domain boundary. One sentence can mix adopted authority, confirmed fact, candidate route, critique, and superseded material; the correct unit is material meaning and its actual authority status.
- **Require a minimum word count:** rejected because length neither proves contract fidelity nor prevents information loss. It would punish small Missions and reward repetition.
- **Require `context.md` or an attachment for every Mission:** rejected because most settled Missions need no extra preservation ceremony. A durable context record is created only when material information would otherwise be lost.

## Consequences

Compression must be checked in two directions: the Brief must preserve the adopted contract, and every material non-contract fact must remain recoverable from a durable, accurately labeled source. When the only source is transient and cannot be preserved within the authorized handoff, the Mission is not ready to hand off.
